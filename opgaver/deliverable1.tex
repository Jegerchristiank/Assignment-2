\subsection{Deliverable 1: Description of the Routine Based on the Interview}
\label{sec:deliverable1}

\paragraph*{Scope and notation}
This Part I study uses a single-case self-study design with one participant (the author). The chosen routine is a weekday morning routine.

The interview was conducted on February 18, 2026 as a self-recorded, semi-structured interview with open questions. Following \textcite{guidehealthinformatics2026ch27}, this stage is treated as \textit{manual knowledge acquisition}: it captures \textit{knowledge-as-stated} and establishes a first \textit{work-as-imagined} model of the routine \parenciteshort{guidehealthinformatics2026ch27,zajac2026methodsknowing}. This placement is consistent with textbook Figure 27.1 from \textit{Guide to Health Informatics}, where model acquisition precedes formal computer reasoning (Appendix~\ref{app:textbook_figures}, Figure~\ref{fig:textbook_27_1}).

Identifier convention used in this report:
\begin{itemize}
  \item \textbf{Axx} = \textit{activity} IDs from the interview-based model (e.g., A01-A09).
  \item \textbf{Exx} = \textit{event} IDs from the observed event log (e.g., E03, E10).
  \item \textbf{Dxx} = \textit{delta} IDs in the comparison sheet (e.g., D01-D06).
  \item \textbf{Mx} = \textit{method} IDs from the Part II DQ toolkit (e.g., M2, M10).
\end{itemize}
The model notation \textit{DCR} denotes \textit{Dynamic Condition Response} graph modelling.

The routine boundary is defined as start when the alarm sounds and end when the apartment door closes, based directly on transcript lines L21-L22 in Table~\ref{tab:app_transcript_part1}. The baseline sequence (wake-up, hygiene, dressing/packing, breakfast, checks, departure) is grounded in lines L02-L12, and variation points (snooze, breakfast substitution, key search, occasional roommate coordination) are grounded in lines L14-L18. This line-level grounding makes the interview model auditable.

Routine boundary:
\begin{itemize}
  \item Start: alarm sounds.
  \item End: participant leaves home (door closes).
\end{itemize}

Table~\ref{tab:d1_activity_spec} presents the interview-based activity model, and Figure~\ref{fig:d1_dcr_graph} shows the corresponding \textit{interview-based DCR} graph exported from DCR Graph. The graph was built from activities A01-A09 and used as the baseline representation for comparison against the observed event log in Deliverables 2 and 3.

Assumptions used for modelling:
\begin{itemize}
  \item The model represents a weekday baseline (not weekend behavior).
  \item The participant is the only consistent human actor in the routine.
  \item Expected times are recall-based interview estimates and are treated as approximate.
\end{itemize}

These assumptions delimit model scope and support transparent comparison between \textit{knowledge-as-stated} and observed evidence in Deliverables 2 and 3.
